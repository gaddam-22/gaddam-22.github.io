# Personal Profile Website

## Files
- `index.html` — webpage structure/content
- `style.css` — styling, layout and responsive design
- `profile.jpg` — add your own profile photograph here

## Before submission
1. Replace `profile.jpg` with your photograph.
2. Replace the placeholder email/GitHub/LinkedIn links in `index.html`.
3. Check your name, education and experience details.
4. Open `index.html` in a browser and test every navigation/contact link.
5. Upload the files to a public GitHub repository.
6. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
